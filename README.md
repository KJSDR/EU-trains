# European Train Station Density Map

A choropleth visualization showing the distribution of train stations across European countries using D3.js.

## What it shows
This interactive map answers: **Which European countries have the most train stations** 

Countries are colored from light to dark blue based on their total number of train stations. Hover over any country to see detailed breakdowns of station types (main, city, airport, and regular stations).

## Built with
- D3.js v7
- European GeoJSON boundaries
- Train station dataset with 64,000+ entries
